# JARVIS ZERO — Evaluation Contract

Phase One is evaluated independently from model output. Passing text generated by an agent is not evidence.

## Current gates

1. Existing Node/Slack type checks and tests remain green.
2. Python kernel unit tests verify DAG gating, cycle rejection, failure propagation, capability scoping, persistence/restart, failure capture, and protocol validation.
3. A JavaScript integration test must successfully communicate with the Python kernel through the real stdio bridge.
4. The C++ native target must compile with strict warnings and its bounded-queue test must pass.
5. CI runs all three language gates on every push and pull request.

## Metrics to add before optimization claims

- orchestration latency p50/p95/p99
- ready-queue scheduling throughput
- persistence latency
- bridge serialization/IPC latency
- peak RSS
- recovery time after worker termination
- task-loss count
- context/token volume per completed objective

No speed, memory, reliability, or token-reduction target may be claimed without a frozen benchmark definition and before/after measurements.
